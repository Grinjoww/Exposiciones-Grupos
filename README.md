Grupo #3: Alpine.js
Integrantes:
Loor
Figueroa

Explicó el uso de Alpine.js junto con SQLite, resaltando que esta última es una base de datos ligera y embebida.
Durante la demostración mostraron cómo levantar el frontend y el backend de forma sencilla y cómo realizar peticiones al servidor.
También presentaron el uso de Swagger para documentar las API, además de funciones como x-show, x-model y fetch para el manejo de errores, validaciones y comunicación con el backend mediante tokens.
Aunque la exposición fue clara y práctica, se comentó que el proyecto no siguió completamente las consignas, ya que no consumía directamente las API de Spring Boot.
Finalmente, mencionaron que Alpine.js es útil para proyectos simples, pero tiene limitaciones para desarrollos más grandes.
