grupo 3 (ALPINE.JS)
Loor
Figueroa

Explicó el uso de Alpine.js junto con SQLite, resaltando que esta última es una base de datos ligera y embebida. Durante la demostración mostraron cómo levantar el frontend y el backend de forma sencilla y cómo realizar peticiones al servidor. También presentaron el uso de Swagger para documentar las API, además de funciones como x-show, x-model y fetch para el manejo de errores, validaciones y comunicación con el backend mediante tokens. Aunque la exposición fue clara y práctica, se comentó que el proyecto no siguió completamente las consignas, ya que no consumía directamente las API de Spring Boot. Finalmente, mencionaron que Alpine.js es útil para proyectos simples, pero tiene limitaciones para desarrollos más grandes.

El grupo 4, representado por Pallo, explicó la configuración inicial de Next.js utilizando npm y npx, destacando que el frontend se encarga únicamente de la interfaz y consume las API desarrolladas en Spring Boot mediante la URL del backend. También mostró cómo se estructuran las peticiones, las validaciones y la importancia de "use client" para ejecutar correctamente ciertas funciones. La demostración se centró en la organización del proyecto y la creación de las carpetas principales, aunque dedicó más tiempo a mostrar los resultados en Postman y Docker que al funcionamiento del frontend en la aplicación.
